## 🚀 Run Locally

### Requirements

- Node.js **22.5+**
- Git

### 1. Clone

```bash
git clone https://github.com/toobahashim5/coffee-management-system.git
cd coffee-management-system
```

### 2. Install Dependencies

```bash
cd backend
npm install
```

### 3. Start the Server

```bash
npm start
```

### 4. Open in Browser

```text
http://localhost:3000
```

The backend automatically serves the frontend.
